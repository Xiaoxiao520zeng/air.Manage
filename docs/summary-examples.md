# 总结示例（照着这个样子填就行）

下面三份都是**填好的示例**，人名、日期、内容都是编的，只看格式和写法。实际提交时，用成员指南里的方法生成你自己的文件，把每个栏目里的内容换成你真实做的事情。

先记住文件放哪（每人一个文件，名字必须和成员名单里的写法一模一样）：

| 类型 | 存放位置 | 例子 |
| --- | --- | --- |
| 日总结 | `summaries/日期/名字.md` | `summaries/2026-11-08/张三.md` |
| 周总结 | `summaries/weekly/年-W周数/名字.md` | `summaries/weekly/2026-W46/张三.md` |
| 知识黑板 | `blackboard/日期-名字.md` | `blackboard/2026-11-08-张三.md` |

写法约定（负责人定，见团队资料里的协作约定）：

- 日总结可以借助 AI 辅助整理；**周总结必须本人手写**，下面周总结示例只示范格式，不要照着仿写内容。
- 日总结、周总结都没有字数要求，把事情写清楚即可：做了什么、结果怎样、卡在哪、接下来做什么。

## 日总结示例

文件名：`summaries/2026-11-08/张三.md`

```markdown
# 日总结

- 作者：张三
- 日期：2026-11-08

## 今日完成

- 把 450 机架的四个电机和电调焊接完成，通电测试转向正确。
- 飞控参数按教程初始化，GPS 室外搜星 14 颗，定位正常。

## 遇到的问题

- 3 号电机启动时抖动，怀疑电调信号线接触不良，明天换线验证。
- 需要协助：想借一台电调测试仪，排查是电调问题还是电机问题。

## 明日计划

- 排查 3 号电机抖动，换线后重新通电测试。
- 装桨做第一次系留试飞，记录悬停稳定性。
```

## 周总结示例

文件名：`summaries/weekly/2026-W46/张三.md`

```markdown
# 周总结

- 作者：张三
- 周期：2026-W46

## 本周完成

- 完成整机组装和飞控初始化。
- 系留试飞 2 次，姿态模式下悬停稳定。

## 本周收获

- 学会用万用表排查电源短路：先断电测通断，再逐段排除。
- 电调油门行程要四个一起校准，单个校准会导致启动不一致。

## 遇到的问题

- 悬停时有轻微漂移，还没定位是罗盘干扰还是重心偏移。

## 下周计划

- 换空旷位置重新校准罗盘，验证漂移是否消失。
- 开始练定点模式下的简单航线飞行。
```

## 知识黑板示例

文件名：`blackboard/2026-11-08-张三.md`

```markdown
# 知识黑板

- 作者：张三
- 日期：2026-11-08

## 分享主题

电调油门行程校准：为什么四个电调必须一起校准。

## 适用场景

新装机第一次通电、更换电调或飞控之后；电机启动不一致、有的转有的不转时也要重新校准。

## 关键步骤

1. 拆掉所有桨叶，接下来的操作全程无桨。
2. 遥控器油门推到最高，再给飞机通电，听到电调提示音后把油门拉到最低。
3. 断电后重新通电，依次给每个电机少量油门，确认四个电机启动时机一致。

## 示例或练习

两人一组：一人读步骤、一人操作。校准完成后，听四个电机在低油门下的转速声是否一致，不一致就重做一遍并记录是哪一步出了问题。

## 讨论与补充

（其他成员看完有问题或补充，写在这里。）
```
