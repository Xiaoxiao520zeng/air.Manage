# 2026-11-16 工作总结 · 姚天宇

## 今日完成

1. **把整机线束按功能分了类，先理清「有哪些线」**：
   - **电源线**：电池 → 分电（PDB / 分电板 / 电调直焊）、电调 → 电机三相线；
   - **信号线**：飞控 ↔ 电调（PWM / DShot）、接收机 ↔ 飞控、GPS / 罗盘 ↔ 飞控；
   - **图传与视觉**：摄像头 → 图传（视频信号 + 供电）、图传天线馈线；
   - **载荷与辅助**：云台供电与控制、蜂鸣器 / LED、舵机（后续机构用）。
   分类之后才明白，之前觉得「线很多」其实是四条独立链路混在一起看，拆开就没那么乱。
2. **逐个认了接口，整理成清单（型号 / 针数 / 用途 / 线径）**：
   - 电源类：XT60（主电源）、XT30（分支或小功率）、JST 插头（小电流供电）；
   - 信号类：JST-GH 1.25（飞控与电调、接收机常用）、JST-SH 1.0、杜邦 2.54（舵机 / 调试）；
   - 焊接类：电调与电机三相焊盘、飞控电源焊盘；
   - 线径按用途分档记录：大电流 14~16AWG，小电流供电 20~22AWG，信号 26~28AWG。
3. **理清了线束管理的思路，按四步走**：
   - **先规划再动手**：先画接线拓扑图（谁连谁、走哪条路），再定线长和插头，避免装到一半发现线不够长；
   - **分区走线**：动力线与信号线分开走，图传馈线和罗盘尽量远离大电流路径，减少干扰；
   - **固定与防护**：扎带定位 + 螺旋缠绕管 / 编织网管，关键焊点加热缩，机架穿孔处加护线圈防磨；
   - **可维护性**：能插接的不焊死、留检修余量、每条线两端贴标签、颜色按约定区分（红正黑负，信号统一色）。
4. **定了几条自己的执行约定**：电源线一律红正黑负；每根线两端贴标签（编号 + 用途）；多余线长盘成圈固定在机架上，不散着塞；焊完先目视检查锡量再通电。
5. **产出一张接线拓扑草图和一份接口清单表**，标出已买配件用到的接口、还缺哪些转接线，作为下一步采购和装机的依据。

## 遇到的问题

- **接口型号太杂，实物容易混**：JST-GH 1.25 和 JST-SH 1.0 外观接近，手上没有卡尺和规格书，光看图片分不清，容易买错转接线。
- **线径与电流还没定量**：目前只按经验分了 14~16AWG、20~22AWG、26~28AWG 三档，具体到电调峰值电流该用多粗、线长了会掉多少压，还没算过。
- **走线空间和结构打架**：机臂内走线会和折叠件干涉，从机臂外走又影响外观和抗摔，方案还没定。
- **标签和颜色的规范只在自己脑子里**：还没形成团队统一约定，担心后面几个人一起装机时接错。
- 需要协助：想借一把卡尺量接口实物尺寸；想确认团队是否已有统一的接口 / 插头标准（比如统一用 JST-GH 还是 XT30），有的话我按标准买转接线；另外想问问有没有万用表可以借，做线序和通断检查。
