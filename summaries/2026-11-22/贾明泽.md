## 今日完成

1. **确定了跨设备的分工**：Jetson 板子跑主程序与算法（OpenVINS、EGO-Planner），Windows 只负责可视化。
   - 连接方式定为**同一局域网**：Windows 用 **SSH** 登录并管理 Jetson；Jetson 把运行数据实时发给 Windows 上已装好的 **Lichtblick**（1.31.0，已确认安装并打开）。
   - 待核对：Jetson 当前 IP、SSH 账号与密码、`obstacles.json` 在板子上的实际路径——这几项还没有确认。
2. **纠正了一处职责划分**（今天比较重要的一次自我修正）：
   - 原来我说的「用 OpenVINS 做避障」，其实 OpenVINS **只估计相机在哪、朝哪、怎么动**，它不产生障碍物信息，也不规划路径；
   - 真正的分工是：**OpenVINS 出位姿 → 深度/点云出障碍 → EGO-Planner 出轨迹**。避障这件事必须要有深度数据或障碍地图作为输入，光靠这两个算法的名字不能说明链路已经跑通。
3. **把 OpenVINS 的原理过了一遍**（视觉惯性状态估计，MSCKF 思路）：
   - 图像里找可重复识别的点（树干纹理、墙角），下一帧再找同一批点，得到「点在画面里移动了多少」；
   - IMU 的陀螺仪快速给出转动、加速度计给出受力，用来**预测短时间内的运动**（快，但误差会累积）；
   - 用图像反过来**修正**预测：如果按预测树干该在画面左侧、实际却更靠中间，就调整位姿估计；
   - 不断重复并保留最近一段时间的状态，输出轨迹。
   - 关键限制：这个「定位」是**相对启动位置**的（启动处记作 0,0,0），不是校园里的绝对坐标；跟踪丢失、时间不同步、相机与 IMU 标定不准都会让轨迹漂移。位姿数据本身**不会指出细树枝在哪**。
4. **把 EGO-Planner 的原理过了一遍**（局部规划）：
   - 输入是当前位姿、局部障碍、目标点、运动限制，输出是**带时间的局部飞行轨迹**；
   - 做法是在空间里摆一排可调整的点，拉出一条平滑曲线；碰到障碍的部分被推向可通行一侧，同时限制曲线不要过度弯折（平滑、碰撞、运动可行性三类代价）；
   - 如果要求的速度/加速度超了，就**拉长经过这段路的时间**再重算；
   - 它是**局部**规划器：新障碍出现、位置变化都要用新数据重算；名字里的 **ESDF-free** 是不预先算整片空间的「离障碍多远」距离场，只着重处理轨迹实际碰到的障碍，**不等于不需要障碍地图**。
5. **理清了 Jetson 上应有的数据链**：
   - 相机图像 + IMU → OpenVINS → 当前位姿；
   - 相机深度/点云 → 障碍感知 + 局部地图 → 障碍位置；
   - 位姿 + 障碍 + 目标 → EGO-Planner → 规划轨迹；
   - 轨迹、障碍、目标这些**都在 Jetson 上算完**，Windows 的 Lichtblick 只负责显示。
6. **定了下一步的验收顺序**（先本地、后联调）：先在 Jetson 上分别确认 OpenVINS 能持续输出位姿、障碍数据能更新、EGO-Planner 能输出规划轨迹；主程序稳定之后，再把相机画面、实际轨迹、障碍和规划轨迹实时接到 Windows 的 Lichtblick。

## 遇到的问题

- **概念上把「定位」和「避障」混成一件事**：一开始以为上了 OpenVINS 就等于能避障，实际上避障还缺深度感知和规划两块，这个误解会直接影响后面查问题的方向。
- **规划轨迹 ≠ 飞控会执行**：画面上出现一条规划线，只能证明程序输出了线，不能证明它没穿过障碍、没超运动限制，更不能证明飞控真的按它飞了。这条要写进验收清单。
- **定位丢失时的行为还没定义**：现在没有明确「定位丢了以后规划器输出什么」，是继续输出、停住、还是清空？不定义清楚，联调时会看到迷惑现象。
- **时间同步是个隐患**：视频、IMU、深度、规划结果分属不同来源，接 Lichtblick 时如果时间戳对不上，界面会表现为「画面在动但轨迹不动」。
- **整条链路目前都还没有实证**：Jetson 的 IP/SSH 没核对、`obstacles.json` 位置没确认、OpenVINS 与 EGO-Planner 是否已接真实相机数据、两者之间是否真的在传结果——这些全是「说过但没看过」。

## 附：模块职责与输入输出

| 模块 | 主要输入 | 主要输出 | 解决的问题 |
| --- | --- | --- | --- |
| OpenVINS | 连续相机图像、IMU 的加速度与角速度 | 位置、朝向、速度等运动估计 | 「我怎么动了？」 |
