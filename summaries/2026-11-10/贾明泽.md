# 2026-11-10 日总结 · 贾明泽

## 今日完成

1. **用 USB-TTL（CH340）直驱 SG90 舵机，搞清楚为什么驱不动**：CH340 没有 GPIO，TXD 只会按 UART 协议逐位输出「先低后高」的波形，而舵机只认「高电平持续多久」——两者正好反相。按 3600 波特算，1 位 = 0.278 ms，发 `0xFE` 实际得到「低 0.56 ms + 高 19.4 ms」，舵机量到 19.4 ms 的高脉冲，远超 2.5 ms 上限，只会顶到限位嗡嗡响。
2. **写脚本把结论验证了一遍**：`servo\sg90_ttl.py`（3600 波特 bit-bang，8 档、步进约 26°）、`probe_port.py`（探口）、`test_move.py`（单次动作）、`spin.py`（固定串口持续转动）。
3. **确定正确路线并对比方案**：要标准 PWM（50 Hz、544~2400 µs）必须用带 GPIO 和定时器的芯片。对比 Arduino Nano（约 15 元）、三极管 + 电阻反相（约 3 元）、舵机测试仪（约 8 元），最终选手上现成的 89C52RC。
4. **把 89C52 整条链路打通**：SDCC + `build.bat` 一键编译、stcgal 烧录（蓝色开关断电再上电）、定时器实测输出 50 Hz / 0.5~2.5 ms 微秒级精度、`servo52_tune` 支持串口在线改脉宽不用重烧。
5. **验证舵机真实行程**：500 µs 与 2500 µs 能稳在两个不同角度，说明定位舵机与线路固件都没问题；把脉宽放宽到 350~2650 摆幅毫无变化，说明限制来自**机械行程**，不是信号范围。

## 遇到的问题

- **TTL 直驱天生不可行**：每个字节尾巴都带停止位（高电平），会在 20 ms 周期里插进一串 0.28 ms 的尖刺，把 PWM 打碎；可用档位只有 8 个。
- **串口一开始打不开**：`serial.Serial(port…)` 抛 `serialwin32` 异常，COM5 不可用；后来装好 CH340 驱动才通。
- **这颗舵机转不满标称 180°**：实际行程比标称小，代码怎么写都变不出整圈，限位挡块就在那儿。已把脉宽收回到 525~2475 µs，避免长时间顶限位磨损。
- **在线调参不持久**：`servo52_tune` 的参数写在 RAM 里，断电就恢复默认 500/2500，调好的数值必须回写进固件。
