## 今日完成

**OAK-D Pro 深度测距跑通，并在做不同条件下的精度对比。**

**1. 深度测距链路打通**

- 用 DepthAI 起流：左/右目 + 深度图同步输出，确认深度图与彩色图对齐
- 取距方式：在目标位置取小 ROI（约 30×30 像素）求中值与均值，两种口径都记，避免单个像素噪声带偏读数
- 单位口径确认：深度流单位是毫米，输出换算成米，与图纸/器件尺寸统一

**2. 精度对比（今天主要在做的事）**

分几个维度在比，目标是把"能测"变成"知道多准"：

- **距离**：近距离到远距离分段取点，看误差随距离怎么变（双目深度误差基本随距离平方增长，基准是基线²×焦距）
- **目标表面**：白墙、纸板、深色物体、有纹理/无纹理表面，看深度空洞（值为 0 或无效）的比例差多少
- **ROI 大小**：同一个点用 10×10 / 30×30 / 60×60 三种窗口取中值，看读数抖动与边缘混合的影响
- **光照**：室内常规光与侧光/弱光下的差异（双目靠纹理匹配，光照太平或过暗都会掉点）

**3. 与项目需求的对照**

- 现有需求是固定杆挂接点测距，距离量级在 0.5–3 m，这个区间正好是 OAK-D Pro 的舒适区；超过 5 m 误差会明显放大，不适合做远距测量
- 细杆（直径 2–3 cm）是已知难点：杆体在深度图上容易出空洞，需要靠杆前后的背景深度做补偿，或者改用"选点+局部拟合"

## 遇到的问题

1. **深度空洞与边缘混合**：无纹理表面、细杆、远景边界处读数缺失或跳到背景，单点取值不可靠，必须做 ROI 聚合 + 有效性判断（无效帧要丢弃，不能当 0 处理）。
2. **误差随距离增长明显**：近距（1 m 内）读数稳定，远距抖动变大，需要按距离分段给误差指标，而不是给一个统一的"精度 ±X cm"。
3. **缺少统一测试基准**：目前是手动在不同位置取点，缺少固定距离标尺，数据之间可比性不强，需要做一套固定点位的测试表。
4. **与贾明泽的选点方式还没统一**：他在做挂接点定位，我在做测距精度，两边如果 ROI 口径和选点规则不一致，后面的误差数据没法直接对比。

## 附录：双目深度误差速记

| 影响因素 | 表现 | 应对 |
| --- | --- | --- |
| 距离 | 误差随距离平方增长（∝ Z²/(f·B)） | 按距离分段给指标，远距不承诺精度 |
| 基线 / 焦距 | 基线越大、焦距越长，远距越准 | 选型阶段定，后期不可改 |
| 表面纹理 | 无纹理/反光 → 空洞 | 补光、贴标记、或用主动红外（Pro 版有 IR 点阵） |
| 目标尺寸 | 细杆边缘混合 → 读数跳背景 | ROI 聚合 + 前后景分离 + 局部拟合 |
| 光照 | 过暗/过曝 → 匹配失败 | 控制曝光，避免逆光 |

结论：0.5–3 m 区间可用，精度口径必须按距离和表面条件分别给；单一"±X cm"的说法在验收时站不住。
