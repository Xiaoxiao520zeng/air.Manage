# 日总结 2026-11-18 梁清华

## 今日完成

**1. 确定无人机整机具体结构（今日主要成果）**

把之前只停留在图纸上的连接关系，收敛成一套可直接照着装的整机结构方案，按「电源层 → 控制层 → 计算感知层」三层划分：

- **电源层**：电池（6S 4600mAh）作顶层动力源 → PMU 2 Lite 取电并输出 15V → 分电板 J1 分出两路 BEC 支路（Matek BEC 12V 供 Jetson、相机稳压 5V 供 OAK）
- **控制层**：飞控 X25 居中安装，电调（四合一）紧贴机架中心，CAN 扩展板侧置出四路预留口
- **计算感知层**：Jetson Orin NX + Y-Adapter + OAK-D-Pro 作为一组前置，USB3 走短线直连，避免绕机一周
- **线束原则**：层内短接、层间集中走线，动力线（6S 主电）与信号线（DShot / UART / CAN）分开走线，线束编号 W01–W15 与图纸一一对应
- 结构定稿后，前面几轮反复讨论的"哪些模块放哪、哪根线走哪"全部落定，后续按此装配与修订

## 遇到的问题

1. **结构定稿但实物未到位**：三层布置按器件手册尺寸排的，实物到手后需复核安装孔位与层间净空，尤其 Jetson + Y-Adapter 那一组的前置长度。
2. **主电源线与结构件干涉未解**：姚天宇 11-17 试装反馈主线与加强筋干涉、部分线长偏紧、插头防呆方向与图纸有出入，这三条要等结构件与线束一起试装时才能定，可能触发 UAV-E-004 REV B。
3. **Jetson 12V 供电仍未实测**：P3768 载板常见 19V，图上按 12V 画，需实测 J16 电压与带载压降后才能定论。
4. **嘉立创专业版导出的是图，不是可制造文件**：这是线缆图/框图，不是 PCB 原理图，不会生成器件网络与封装。
