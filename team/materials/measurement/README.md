# 测距数据归档（相机 / 雷达）

本目录存放测距相关的原始数据、统计结果与脚本，配合 `summaries/` 下对应日期的日总结使用。

## 文件说明

| 文件 | 日期 | 内容 |
|---|---|---|
| `相机测距原始数据-1.5m-2026-11-24.csv` | 2026-11-24 | OAK-D Pro 单点 ROI 测距原始记录，408 条，实际距离 1500 mm，26 个像素点 |
| `相机测距统计-1.5m-2026-11-24.csv` | 2026-11-24 | 按像素点聚合的统计：Z 中位/极值、测量中位、误差、相对误差、异常行数 |
| `相机测距脚本-2026-11-24.py` | 2026-11-24 | 当天使用的取点测距脚本（DepthAI + Tk 界面），含数据落盘逻辑 |

## 原始数据字段

```text
timestamp, pixel_x, pixel_y, z_mm, distance_mm, actual_mm, error_mm, abs_error_mm
```

- `z_mm`：ROI（9×9）内有效深度的中值，单位毫米
- `distance_mm`：由 `√(x²+y²+z²)` 换算到该像素点对应空间点的直线距离
- `actual_mm`：人工输入的实际距离（卷尺值）

## 已知缺陷（2026-11-24 数据）

1. **`distance < z` 异常 236/408 条**：几何上不可能出现，说明该批 CSV 由早期版本脚本写出，Z 与 distance 不同源。判断依据与影响见 `summaries/2026-11-24/梁清华.md`。
2. **无效深度未过滤**：当时只按 `0 < z < 30000` 过滤，未启用 LR check / 置信度阈值 / 量程限制，近场散斑值（约 318 mm）被 ROI 中值吸收，导致 1.5 m 处读数系统性偏小约 66%。
3. **批次用途限定**：这批数据只可用于问题定位，不可作为精度指标引用。

## 使用约定

- 统计一律用**中位数**，不用均值（无效值会在低值区形成离群簇，均值失真）。
- 新增数据请按 `相机|雷达-测距数据类型-距离档-日期.csv` 命名，并同步更新本表。
- 单文件超过 50 MB 前先与负责人确认是否走 Git LFS。
