## 上电前必确认（按设备清单 xlsx「接线要点」sheet）

1. **主电链路**：B1 XT60 → W01 → A1(PMU) BATT-IN；A1 BATT-OUT → W02 → A3(ESC) XT60；同一节点 → W03 → F1 5A → J1 分电板。J1 只带两路 BEC，**不要**给 ESC 供电。
2. **三级电压互不并联**：15V（PMU→飞控 POWER C1，必须 15V 版）；12V（BEC 改焊桥后量过再接 Jetson J16）；5V（相机稳压→Y-Adapter PWR）。所有 GND 共地。
3. **A4(Matek BEC) 出厂默认 5.2V**，必须改到 12V/5A 并实测后再接 Jetson；P3768 载板常见 19V，12V 供电需核对载板手册。
4. **ESC 信号**：W05 8P 只接 M1–M4 信号 + GND，VBAT/TLM/CUR 留空；DShot300；首转去桨、上测试台核对转向。
5. **CAN**：仅总线两端 120Ω，节点 ID 不重复；A6 输出先量 5V 再接 OAK。
6. 去桨、串烟雾测试器；先量 12V/5V，再接负载；6S 下限 20V，建议 21V 落地。
