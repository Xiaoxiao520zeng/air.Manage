# 团队共享资料文件

把团队成员都需要查看的资料放在本目录，例如：

- 演示文稿：`.pptx`、`.ppt`
- 三维模型：`.stl`、`.obj`、`.step`
- 项目参考资料：适合共享的 PDF、图片和文档

建议文件名包含项目/主题、日期和版本，例如：

```text
项目名-方案评审-2026-11-08-v1.pptx
设备外壳-打印模型-2026-11-08-v2.stl
```

文件较多时按项目新建子目录。提交前确认文件适合团队共享，不包含密码、访问令牌或个人隐私。仓库及其历史对所有有读取权限的成员开放。

大型模型或频繁更新的大文件会让 Git 仓库变大；如果单个文件接近 50 MB 或更大，先和负责人确认是否使用 Git LFS。
